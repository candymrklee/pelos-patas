PELOS & PATAS — HTML, CSS E JAVASCRIPT SEPARADOS

COMO ATUALIZAR NO GITHUB
1. Extraia este ZIP no computador.
2. No repositório pelos-e-patas-3, use Add file > Upload files.
3. Envie os quatro arquivos HTML e as pastas css, js e assets.
   Eles devem ficar na raiz do repositório, mantendo as pastas.
4. Confirme a atualização em Commit changes.
5. Abra o site publicado pelo GitHub Pages e atualize a página.

Não envie o ZIP fechado: envie os arquivos e as pastas extraídos.
Mantenha o nome quem-somos.html, com hífen.

ORGANIZAÇÃO
index.html, blog.html, produtos.html e quem-somos.html: conteúdo das páginas.
css/: estilos de cada página, extraídos sem alterar as regras originais.
js/: filtros, carrosséis, agendamento e chat.
assets/: imagens que já estavam no repositório.

A IA local usa js/chat-worker.js e deve ser aberta pelo site publicado
ou por um servidor local. Não é necessário ativá-la para usar as
respostas prontas do chat.

O trabalho usa JavaScript (.js), que é diferente da linguagem Java (.java).

VERIFICAÇÃO
Conferidos os caminhos dos arquivos, a sintaxe dos scripts e a
preservação do conteúdo HTML e das regras CSS. Filtros e carrossel
também passaram por verificações de lógica.
Não foi possível executar a comparação visual no navegador deste ambiente.
